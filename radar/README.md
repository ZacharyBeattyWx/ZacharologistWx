# Radar Frame Service Contract

This directory documents the future site-owned radar frame service for Zacharologist Wx. It is not active yet.

The intended production endpoints are:

```text
/radar/frames.json
/radar/frames/{site}/{product}/{slug}.webp
```

Example:

```text
/radar/frames/KFCX/N0Q/N0B_20260516_0210.webp
```

`frames.example.json` defines the inactive contract shape for the future generated catalog. It includes site metadata, product metadata, frame timing, image dimensions, geospatial bounds, and the palette name used by the renderer.

The frame service must be generated by this site's own backend/renderer. It must not hotlink AgWx, Tehuano Labs, RadarScope, RadarOmega, or any other third-party rendered radar product.

The future backend renderer is expected to:

- fetch public NEXRAD radar data
- decode and render supported products
- apply `DEFAULT_REFLECTIVITY_COLOR_TABLE` for reflectivity products
- export WebP or PNG frames into `/radar/frames/{site}/{product}/`
- update `/radar/frames.json`
- cache generated output

Current homepage radar behavior remains unchanged:

- Clean Radar uses the Windy iframe fallback
- Super-Res Radar uses IEM single-site loop frames for supported products
- Hi-Res Site Radar forces IEM `N0B` and uses the same IEM loop system
